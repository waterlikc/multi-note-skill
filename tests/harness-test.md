# multi-note-skill Harness测试脚本

## 测试目标
验证multi-note-skill在各场景下的生成质量和一致性

## 测试用例

### TC1: 技术教学场景
**输入**: Python并发编程教程
**期望输出**:
- 标题包含"技术教学"
- 包含代码块组件
- 包含对比框（并发模型对比）
- 动画延迟递增

### TC2: 科普教育场景
**输入**: 量子计算入门
**期望输出**:
- 标题包含"科普教育"
- 包含流程图组件
- 包含概念解释
- 语言通俗易懂

### TC3: 学术会议场景
**输入**: 教育技术研讨会
**期望输出**:
- 标题包含"学术会议"
- 包含议程流程
- 包含决策记录
- 包含待办事项

### TC4: 调研分析场景
**输入**: AI认知调研报告
**期望输出**:
- 标题包含"调研分析"
- 包含数据展示
- 包含结论建议
- 结构完整

### TC5: 小说架构场景
**输入**: 无职转生小说分析
**期望输出**:
- 标题包含"小说架构"
- 包含人物分析
- 包含结构分析
- 包含主题总结

## 质量检查清单

### P0 检查（必须通过）
- [ ] HTML文件可正常打开
- [ ] `<title>` 标签已替换
- [ ] `lang="zh-CN"` 已设置
- [ ] 无emoji作为图标
- [ ] CSS样式正确加载
- [ ] 字体正确加载

### P1 检查（强烈建议）
- [ ] 动画延迟从0.1s递增
- [ ] 便签不遮挡正文
- [ ] 流程图箭头正确
- [ ] 对比框标签颜色正确
- [ ] 装饰图标opacity ≤ 0.15
- [ ] 咖啡渍不超过2个

### P2 检查（建议）
- [ ] 响应式布局正常
- [ ] 内容节奏合理
- [ ] 颜色使用一致
- [ ] 组件使用恰当

## 已知问题

### Issue 1: CSS重复
**描述**: 每个HTML文件都内联完整CSS
**状态**: 已通过提取公共CSS解决
**解决方案**: `assets/styles.css`

### Issue 2: 便签溢出
**描述**: 移动端便签可能溢出
**状态**: 已通过响应式CSS解决
**解决方案**: `@media (max-width: 768px)` 规则

### Issue 3: 动画延迟
**描述**: 手动设置动画延迟容易出错
**状态**: 需要文档说明
**解决方案**: 在SKILL.md中明确延迟规则
