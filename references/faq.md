## 基础使用问题

### Q1: 如何触发multi-note-skill？

**A**: 在对话中输入以下任意关键词：
- "生成笔记"
- "帮我做笔记"
- "创建学习笔记"
- "笔记生成器"
- "帮我整理笔记"

### Q2: 如何指定笔记场景？

**A**: 在描述中包含场景关键词：

```
场景关键词映射：
- 技术学习：代码、编程、API、Python、JavaScript
- 课堂学习：课堂、老师、考试、知识点、公式
- 科普知识：科普、原理、现象、实验、入门
- 读书笔记：读书、书评、感悟、作品、阅读
- 会议纪要：会议、议程、决议、行动项、讨论
- 调研分析：问卷、数据、统计、结论、调研
```

### Q3: 如何选择模板？

**A**: 在描述中指定模板类型：

```
用户：用Style B模板生成会议笔记
AI：使用皮革手账本样式，生成翻页式笔记
```

**模板选择建议**：
- Style A：适合日常学习、教学笔记
- Style B：适合正式会议、项目报告

### Q4: 笔记保存在哪里？

**A**: 默认保存在 `D:\blog\notes\` 目录。

可以指定其他目录：
```
用户：把笔记保存到 D:\MyNotes\
AI：[生成笔记并保存到指定目录]
```

### Q5: 可以自定义笔记结构吗？

**A**: 可以，在描述中指定你想要的结构：

```
用户：生成Python教程笔记，结构为：
1. 核心概念
2. 基础语法
3. 代码示例
4. 常见问题
5. 最佳实践

AI：[按照指定结构生成笔记]
```

## 多模态输入问题

### Q6: 如何从图片生成笔记？

**A**: 三种方式：

#### 方式1：直接发送图片
```
用户：[发送图片]
AI：自动识别为图片输入，OCR提取文字，生成笔记
```

#### 方式2：指定本地文件路径
```
用户：把 D:\Screenshots\lecture.png 做成笔记
AI：OCR识别图片文字，生成笔记
```

#### 方式3：提供图片URL
```
用户：把这个图片做成笔记 https://example.com/image.png
AI：下载图片，OCR识别，生成笔记
```

### Q7: 如何从视频生成笔记？

**A**: 提供视频链接即可：

```
用户：把这个视频做成笔记 https://www.youtube.com/watch?v=xxx
AI：提取视频字幕，整理成笔记

用户：把这个B站视频做成笔记 https://www.bilibili.com/video/BVxxx
AI：提取视频字幕，整理成笔记
```

### Q8: 如何从网页生成笔记？

**A**: 提供网页链接即可：

```
用户：把这个网页做成笔记 https://blog.example.com/article
AI：提取网页正文，生成读书笔记
```

### Q9: 如何从音频生成笔记？

**A**: 提供音频文件路径或链接：

```
用户：把 D:\Audio\lecture.mp3 做成笔记
AI：语音转文字，整理成笔记

用户：把这个音频做成笔记 https://example.com/audio.mp3
AI：下载音频，语音转文字，整理成笔记
```

### Q10: 可以混合多种输入吗？

**A**: 可以，支持多模态组合：

```
用户：我今天学了这些，帮我整理成笔记：
- 这张图片是课堂PPT
- 这个视频是配套讲解
- 我还有一些文字笔记

AI：整合多模态内容，生成完整笔记
```

### Q11: OCR识别不准确怎么办？

**A**: 确保图片清晰，文字对比度高：

**优化建议**：
1. 使用高分辨率图片
2. 确保文字清晰，避免模糊
3. 避免倾斜或扭曲的图片
4. 对于手写文字，确保字迹工整

**安装更完整的语言包**：
```bash
npm install tesseract.js
# tesseract.js会自动下载语言数据
```

### Q12: YouTube字幕获取失败怎么办？

**A**: 检查以下几点：

1. **视频是否有字幕**：部分视频可能没有字幕
2. **字幕是否被禁用**：某些视频可能禁用了字幕
3. **网络连接**：确保可以正常访问YouTube
4. **视频地区限制**：某些视频可能有地区限制

**替代方案**：
- 尝试使用其他视频源
- 手动下载字幕文件
- 使用本地视频文件

### Q13: 网页内容提取不完整怎么办？

**A**: 某些网页可能需要JavaScript渲染：

**解决方案**：
1. 尝试使用其他网页源
2. 手动复制网页内容
3. 使用Puppeteer等工具预渲染网页

**支持的网页类型**：
- 博客文章
- 技术文档
- 新闻报道
- 学术论文

## 笔记生成问题

### Q14: 笔记生成失败怎么办？

**A**: 检查以下几点：

1. **输入是否有效**：确保输入内容清晰明确
2. **场景识别**：确保场景关键词正确
3. **模板选择**：确保模板类型正确
4. **网络连接**：确保网络正常（对于多模态输入）

**错误处理**：
- 如果生成失败，会返回错误信息
- 根据错误信息调整输入
- 尝试简化输入内容

### Q15: 笔记内容不准确怎么办？

**A**: multi-note-skill会尽力生成准确的内容，但建议：

1. **检查原始输入**：确保输入内容准确
2. **二次编辑**：生成后可以手动编辑
3. **提供更多信息**：提供更多上下文信息
4. **指定结构**：明确指定笔记结构

### Q16: 笔记结构不符合预期怎么办？

**A**: 明确指定你想要的结构：

```
用户：生成Python教程笔记，结构为：
1. 核心概念
2. 基础语法
3. 代码示例
4. 常见问题
5. 最佳实践

AI：[按照指定结构生成笔记]
```

### Q17: 如何生成更好的笔记？

**A**: 遵循以下建议：

1. **明确主题**：清晰描述笔记主题
2. **指定场景**：明确笔记类型
3. **提供结构**：如果需要特定结构，明确说明
4. **提供上下文**：提供更多背景信息
5. **指定模板**：选择合适的模板类型

## 样式和组件问题

### Q18: 便签在移动端遮挡正文怎么办？

**A**: CSS已包含响应式处理，移动端便签会自动改为内联显示。

**手动调整**：
```css
@media (max-width: 768px) {
  .side-note {
    position: static;
    margin: 10px 0;
  }
}
```

### Q19: 动画不生效怎么办？

**A**: 检查以下几点：

1. **animation-delay是否设置**：确保所有 `.write-in` 元素都设置了 `animation-delay`
2. **CSS是否正确加载**：确保样式文件正确引用
3. **浏览器支持**：确保浏览器支持CSS动画

**示例**：
```html
<div class="title write-in" style="animation-delay:0.1s">标题</div>
```

### Q20: 字体不显示怎么办？

**A**: 检查以下几点：

1. **Google Fonts链接**：确保链接正确
2. **网络连接**：确保可以访问Google Fonts
3. **字体名称**：确保字体名称正确

**本地字体替代**：
```css
/* 使用本地字体 */
@font-face {
  font-family: 'Kalam';
  src: url('./fonts/Kalam-Regular.ttf');
}
```

### Q21: 如何选择Style A还是Style B？

**A**: 根据场景选择：

| 场景 | 推荐模板 | 理由 |
|------|----------|------|
| 课堂学习 | Style A | 轻松活泼，适合个人使用 |
| 科普教育 | Style A | 通俗易懂，适合学习 |
| 技术教学 | Style A | 代码友好，适合技术内容 |
| 学术会议 | Style B | 专业正式，适合展示分享 |
| 调研分析 | Style B | 数据友好，适合报告 |
| 项目报告 | Style B | 结构清晰，适合汇报 |

### Q22: 如何自定义颜色主题？

**A**: 修改 `assets/styles.css` 中的颜色变量：

```css
:root {
  --primary-color: #4A90E2;      /* 主色调 */
  --secondary-color: #7ED321;    /* 辅助色 */
  --text-color: #333333;         /* 文字颜色 */
  --background-color: #F5F5F5;   /* 背景色 */
}
```

## 性能和优化问题

### Q23: 笔记生成速度慢怎么办？

**A**: 优化建议：

1. **简化输入**：减少输入内容的复杂度
2. **指定场景**：明确场景可以加快识别
3. **使用缓存**：相同内容会使用缓存
4. **减少多模态**：多模态处理需要更多时间

**Token优化**：
- 精简SKILL.md，按需读取references
- 使用缓存机制，避免重复计算

### Q24: 如何批量生成笔记？

**A**: 使用批量处理功能：

```
用户：帮我生成以下3个主题的笔记：
1. Python基础语法
2. Python面向对象
3. Python并发编程

AI：批量生成3份笔记
```

**代码示例**：
```javascript
import { processBatch } from 'multi-note-skill'

const results = await processBatch([
  { topic: 'Python基础语法', scene: '技术学习' },
  { topic: 'Python面向对象', scene: '技术学习' },
  { topic: 'Python并发编程', scene: '技术学习' }
])
```

### Q25: 内存使用过高怎么办？

**A**: 优化建议：

1. **减少缓存大小**：调整LRU缓存大小
2. **分批处理**：大量笔记分批生成
3. **清理缓存**：定期清理缓存

**代码示例**：
```javascript
import { clearCache } from 'multi-note-skill'

// 清理所有缓存
clearCache()

// 或者清理特定缓存
clearCache('scene-detector')
```

## 导出和分享问题

### Q26: 如何导出为PDF？

**A**: 两种方式：

#### 方式1：浏览器打印（推荐）
1. 用浏览器打开HTML文件
2. 按 `Ctrl + P`（Windows）或 `Cmd + P`（Mac）
3. 选择"另存为PDF"
4. 调整打印设置
5. 点击"保存"

#### 方式2：使用代码导出
```javascript
import { exportToPDF } from 'multi-note-skill'

await exportToPDF('D:/blog/notes/技术学习-Python并发编程-笔记.html', {
  output: 'D:/blog/notes/技术学习-Python并发编程-笔记.pdf',
  format: 'A4',
  printBackground: true
})
```

### Q27: 如何导出为Markdown？

**A**: 使用Markdown导出功能：

```javascript
import { exportToMarkdown } from 'multi-note-skill'

await exportToMarkdown('D:/blog/notes/技术学习-Python并发编程-笔记.html', {
  output: 'D:/blog/notes/技术学习-Python并发编程-笔记.md'
})
```

### Q28: 如何分享笔记？

**A**: 多种分享方式：

1. **直接分享HTML文件**：发送HTML文件，对方用浏览器打开
2. **导出为PDF**：导出PDF后分享
3. **部署到Web服务器**：上传到Web服务器，分享链接
4. **使用GitHub Pages**：部署到GitHub Pages，免费分享

### Q29: PDF中字体显示异常怎么办？

**A**: 确保网络连接正常，Google Fonts可以正常加载。

**解决方案**：
1. 使用本地字体
2. 嵌入字体到PDF
3. 使用系统默认字体

### Q30: PDF中背景色丢失怎么办？

**A**: 在打印设置中勾选"背景图形"选项。

**Chrome设置**：
1. 打开打印对话框
2. 点击"更多设置"
3. 勾选"背景图形"
