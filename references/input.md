# 无代码平台的内容接入

按本次工具清单与实际返回结果判断，不能靠平台名字猜能力。路径顺序：已提供文字 → 平台原生读附件/识图/转写 → 已配置且获准使用的 API → 请求粘贴内容。只取得部分材料时标明范围，能做的部分先整理。

| 材料 | 可用能力 | 没有能力时的具体请求 |
|---|---|---|
| 图片/PPT 截图 | 原生视觉或已配置 OCR；核对公式、上下标、数字 | 请复制截图中的文字；公式可逐行输入，模糊处标问号 |
| 视频 | 已取得字幕或字幕工具；保留时间戳 | 请从视频字幕面板复制字幕，可先贴一个章节 |
| 网页 | 已授权正文读取工具返回实际正文 | 请复制标题和正文段落，登录页/付费内容不绕过 |
| 音频 | 平台原生转写或已配置转写工具 | 请粘贴转写文字；分辨不了的发言人标未知 |
| 纯文本 | 直接整理 | 长文本按章节拆分，注明未覆盖的范围 |

例如只有视频链接时答：“目前未取得这个视频的字幕。请粘贴字幕或主要讲解段落，我会保留时间标记生成笔记。”不能输出假摘要，也不把 URL 本身渲染成已完成的知识笔记。

## 可选适配器接口
`core/input-adapter.mjs` 提供 `resolveInput(input, adapters, {timeoutMs})`。input 为 `{kind:"image"|"video"|"web"|"audio"|"text", value:"...", label:"来源说明"}`；也可带 `extractedText` 表示已经实际取得的文字。

宿主明确注入 `adapters.image/video/web/audio`：
```js
const adapters = { image: async ({ value, signal }) => {
  const result = await configuredOcr(value, { signal });   // 集成点：宿主已获准使用的 OCR
  return { text: result.text, label: "已配置 OCR 返回内容" };
} };
```

上例 configuredOcr 是集成点，项目未附真实服务。不虚构 URL、密钥、平台 SDK 或已接入状态。适配器只调用一次；超时、权限错误、空结果返回 needs_content，带明确下一步，不进入重试循环。取消信号需由宿主实现实际中止。默认无网络请求，不自动上传附件到外部服务。只有测试替身通过不代表真实 OCR 已验收。

若识别文本与图片数字冲突，以原材料核对；识别置信度只能用服务实际提供的数据，不推算成学习掌握率。

## 三条硬规则（2026-10-21）

- **只有链接不算已读**：先取正文；取不到就请用户粘贴，不能凭 URL 编摘要。
- **识别不确定先问**：适配器返回 `confidence < 0.8` 或 `uncertain: true` 时，返回 needs_content，
  附前 120 字预览，请用户核对数字、公式与专有名词后再生成。
- **超长材料先拆**：单次超过 200,000 字符返回 needs_content，要求按章节拆分；不静默截断、不硬吞。
