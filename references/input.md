# 无代码平台的内容接入

按本次工具清单与实际返回判断，不能靠平台名字猜能力。路径：已提供文字 → 平台原生读附件/识图/转写 → 已配置且获准使用的 API → 请求粘贴。只取得部分材料时标明范围，能做的先整理。

| 材料 | 可用能力 | 没有能力时 |
|---|---|---|
| 图片/PPT | 原生视觉或已配置 OCR；核对公式、上下标、数字 | 请复制截图文字；模糊处标问号 |
| 视频 | 平台 ASR/视频理解，或公开字幕；保留时间戳 | 请从字幕面板复制，可先贴一节 |
| 网页 | 已授权正文读取返回实际正文 | 请复制标题和正文；不绕过登录/付费 |
| 音频 | 平台转写或已配置工具 | 请粘贴转写；分辨不了的发言人标未知 |
| 纯文本 | 直接整理 | 长文按章节拆分，注明未覆盖范围 |

只有链接、转写又取不到时答：“目前未取得这个视频的字幕或转写。请粘贴字幕或主要讲解段落，我会保留时间标记生成笔记。”不输出假摘要，也不把 URL 当成已完成的知识笔记。

## 可选适配器
`src/input.mjs` 提供 `resolveInput(input, adapters, {timeoutMs})`；input 为 `{kind, value, label}`，可带 `extractedText`。宿主可注入 `adapters.image/video/web/audio`，适配器只调用一次；超时、权限、空结果返回 needs_content，不重试。默认不联网、不上传附件；项目未附真实服务，测试替身不等于真实 OCR 已验收。识别文本与图片冲突时以原材料为准；置信度不换算成掌握率。

## 三条硬规则
- **只有链接不算已读**：先取正文；取不到就请用户粘贴，不能凭 URL 编摘要。
- **识别不确定先问**：`confidence < 0.8` 或 `uncertain: true` 时返回 needs_content，附预览请用户核对。
- **超长材料先拆**：超过 200,000 字符按章节拆分，不静默截断。

## 视频链接
1. `detectVideo` 识别平台与 id；识别不到也按视频处理，不猜内容。
2. 没有字幕/转写就返回 needs_transcript，请用户粘贴字幕并保留 `00:12` 这样的时间戳；不凭标题编摘要。
3. 平台原生视频理解/转写可用时，用适配器取回全文再生成。
4. 字幕进 sources：label 写「第 3 段 · 12:40」，text 保留原话；章节 sourceIds 指向它；补充标 supplement。
5. 本地 `node cli/note.mjs video <链接> [来源.json]` 只读公开接口，不登录、不绕权限；ready 写入时间戳 sources，needs_transcript 转告并停，error 说明失败。平台优先用宿主 ASR/视频理解。
