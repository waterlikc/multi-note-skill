# 概念动画（animation）参考

> 只在**程序模式**使用；直接生成模式不要写 CSS/SMIL 动画，保留静态分镜与步骤列表。
> 动画是笔记的一部分，不是视频；默认无脚本、可打印、可降级。
> 精简入口：references/animation.md；完整规格见本文。

## 1. 什么时候用

抽象过程用文字讲不清“先后、因果、状态变化”时：

- 流程：TCP 三次握手、DNS 解析、请求生命周期、CI 步骤；
- 状态机：TCP 状态、订单状态、组件生命周期；
- 时间线：HTTP/1.1→2→3、协议/版本演进。

不要用动画替代定义、公式、代码和例题；一个概念一个动画，最多 8 步。

## 2. 块结构

```json
{
  "type": "animation",
  "id": "tcp-three-way",
  "preset": "flow",
  "title": "TCP 三次握手",
  "alt": "客户端与服务器之间三次报文交换的动画示意",
  "caption": "第三次 ACK 后双方进入 ESTABLISHED",
  "loop": true,
  "motion": "precise",
  "nodes": [
    {"id": "client", "label": "客户端", "detail": "CLOSED", "tone": "accent"},
    {"id": "server", "label": "服务器", "detail": "LISTEN", "tone": "ink"}
  ],
  "edges": [
    {"id": "syn", "from": "client", "to": "server", "label": "SYN seq=x"},
    {"id": "synack", "from": "server", "to": "client", "label": "SYN+ACK"},
    {"id": "ack", "from": "client", "to": "server", "label": "ACK"}
  ],
  "steps": [
    {"id": "s1", "label": "客户端发 SYN", "detail": "进入 SYN-SENT", "focus": ["client", "syn"], "hold": 1.6},
    {"id": "s2", "label": "服务器回 SYN+ACK", "detail": "进入 SYN-RCVD", "focus": ["server", "synack"], "hold": 1.6},
    {"id": "s3", "label": "客户端回 ACK", "detail": "双方 ESTABLISHED", "focus": ["client", "server", "ack"], "hold": 1.8}
  ]
}
```

## 3. 字段规则

| 字段 | 规则 |
|---|---|
| id | 字母/数字开头，全笔记唯一 |
| preset | flow / state / timeline |
| title | 2–40 字 |
| alt | 8–160 字，读屏用；必须描述“发生了什么” |
| caption | 可选，≤120 字；解释动画的边界 |
| loop | 布尔，默认 true |
| motion | 可选 calm / precise / lively；不写则随主题（A 舒缓、B 精准、C 轻快） |
| nodes | flow/state 2–6 个；timeline 不需要 |
| edges | flow/state 1–8 条；timeline 不需要 |
| steps | 2–8 步；每步 label 1–24 字，detail ≤48 字 |
| hold | 0.8–4 秒；总时长 4–20 秒 |
| focus | 0–4 个节点/边 id；只能引用本块 |
| tone | accent / ink / muted / warn / ok |

不允许：原始 SVG/HTML、任意 JS、外部图片、超长标签、自造颜色。

## 4. 三个预设

### flow

有向流程；1–3 个节点单行，4 个节点 2×2，5–6 个节点 3+2。边自动从节点边缘出发，重复边会用上下弧线分开。

### state

状态机；节点环形/网格排列，迁移边带箭头；支持自环。

### timeline

里程碑；只写 steps，不需要 nodes/edges。每个里程碑有圆点、标题、detail，横向排列。

## 5. 渲染行为

- 进入页面自动播放，一轮 4–20 秒；
- 当前步骤：节点/边高亮，其他内容降噪；
- 节点按 motion 入场：calm 上浮淡入、precise 轻微缩放、lively 弹性放大；
- 边按步骤绘制，小圆点沿边移动，标出“报文正在走”；
- timeline 里程碑按步骤逐个出现，游标匀速推进，不再一开始全部点亮；
- 图下显示步骤字幕；正文里保留完整步骤列表；
- “暂停 / 继续”是纯 CSS checkbox，无脚本；暂停会同时停住节点、边、圆点、字幕和游标。实现上用 `.anim-stage { --anim-run }` 统一控制 `animation-play-state`，以后新增动画元素也不会漏掉；
- 打印：关闭动画，显示最终帧 + 全部步骤；
- `prefers-reduced-motion: reduce`：直接显示最终帧 + 步骤列表；
- 手机：SVG 等比缩放，步骤列表纵排；
- 三主题沿用 `--ink/--accent/--line/--paper`，不引入新色板；
- 动效节奏随主题：A 杂志=calm，B 蓝图=precise，C 手账=lively；块内 `motion` 可覆盖。

### 示例

| 文件 | 预设 | 主题/节奏 | 时长 | 说明 |
|---|---|---|---|---|
| `examples/tcp-handshake.json` | flow | B/precise | 5.0s | 三次握手，报文逐条出现 |
| `examples/motions/tcp-state.json` | state | B/precise | 5.5s | 四个状态环形迁移 |
| `examples/motions/http-timeline.json` | timeline | A/calm | 5.4s | HTTP 版本逐个点亮 |
| `examples/motions/binary-search.json` | flow | C/lively | 6.1s | 区间每次砍半 |

`examples/motions/index.html` 是单文件画廊（GIF 内嵌，离线可看）；`examples/motions/README.md` 给出重生成命令。

## 6. 质量检查

渲染后必须：

1. `node scripts/audit.mjs` 通过；
2. `node scripts/lint.mjs note.json out.html` 通过；
3. 浏览器打开：动画循环、暂停可用、打印有最终帧；
4. 系统“减少动态”后静态可读；
5. 375px 不横向滚动。

自动测试在 `tests/animation.test.mjs`。

## 7. 平台/无执行工具

平台只有 write_file 时：

- 不要写 CSS 动画或 SMIL，避免模型编造不可验证的代码；
- 用静态 SVG 分镜 + 步骤列表表达同一信息；
- 在文末注明“静态分镜，动画需程序模式”。

## 8. 限制

- 只有 flow/state/timeline，没有 compare；
- 不做 TTS/配音/视频编码；
- 不做任意坐标/任意 SVG；
- 动画只辅助理解，不替代文字、公式和练习；
- 不宣称提升成绩，只记录“可复看/可打印”。
