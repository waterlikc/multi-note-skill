# 平台录屏操作卡（最终视频用）

> 目标：一次录完四段，少返工：一条完整的操作记录，比切片更好核对。
> 前提：平台已登录；账号、组织名可打码；只展示自己的会话。

## 一、录前 5 分钟

- [ ] 浏览器缩放 100%，分辨率 1920×1080；
- [ ] 关掉微信/QQ/邮件通知；
- [ ] 打开：登录页、工作区、技能管理、对话页；主会话已登录时，用无痕窗口录登录，不要退出主会话；
- [ ] 技能管理只留 `multi-note-skill-v320-final` 开启；旧 `v321` 关闭；
- [ ] 准备一段 JavaWeb 材料（纯文本，≤2000 字）；
- [ ] 本地打开：课程包 index、审计反例终端、笔记 HTML；
- [ ] OBS：显示器采集 1920×1080，30fps，麦克风开，光标高亮。

## 二、四段录屏（3 分 20 秒）

### 第 1 段 登录（0:00–0:15）

1. 从登录页开始录；
2. 输入账号（打码/遮住），输入密码（不显示）；
3. 点登录，进入工作区；
4. 停 1 秒，让观众看清平台名。

### 第 2 段 功能面板（0:15–0:35）

1. 工作区首页：左侧“新建任务 / 技能管理 / 项目记忆 / 任务”；
2. 点“技能管理”，展示技能广场 / 我的技能；
3. 搜索 `multi-note-skill-v320-final`，展示已启用状态；旧 `v321` 关闭。

### 第 3 段 技能调用（0:35–1:40）

1. 新建任务/对话；
2. 挂载技能（输入 @ 或点技能按钮）；
3. 粘贴 JavaWeb 材料；
4. 发送，等生成；
5. 展示 8 节摘要（目标、生命周期、参数、Session、JDBC、Filter、部署、自测迁移）；
6. 点项目文件 `JavaWeb学习笔记.html`，保留“该文件暂不支持预览”提示 1 秒；
7. 点卡片右侧“…”→“下载”，展示下载完成；
8. 如果生成慢，后期 2× 加速，不要剪掉“正在生成”。

### 第 4 段 使用效果（1:40–2:50）

1. 打开下载后的 HTML（本地，字幕标注“平台生成，下载后打开”）；
2. 点学习路径编号跳章节；
3. 点关键词跳命中位置；
4. 切夜间，展示屏幕深色；
5. 打开打印预览，展示浅色；
6. 打开课程包 index：6 份 / 60 节 / 27 词 / 0 问题。

> 平台内预览仍不支持；不要用本地三主题效果冒充平台预览。下载这一步本身就是“产物能带走”的证据。

### 第 5 段 审计与收尾（2:50–3:20）

1. 终端跑：node cli/note.mjs audit 审计反例；
2. 展示“✗ 来源链接必须使用 https / 退出码 1”；
3. 收尾一句话，停 1 秒。

## 三、不要录进去

- 其他同学的会话、姓名、学号；
- 账号密码、手机号、邮箱；
- 组织内部文件列表（可打码）；
- 与作品无关的聊天记录。

## 四、交付

- 原片：1920×1080 MP4，30fps；
- 音频：麦克风原声，不要背景音乐；
- 命名：platform-raw-01.mp4 … platform-raw-05.mp4；
- 不要自己剪，交原片给我统一剪、加字幕、压到 3–4 分钟。

## 五、如果录不了

- 不要用静态截图冒充录屏，也不要把“下载后本地打开”剪成“平台内预览”；
- 不要提交 93 秒草案；
- 先交技术文档/PPT/源码，视频等账号；
- 在提交说明里写“平台录屏待补”，不要写“已完成”。
