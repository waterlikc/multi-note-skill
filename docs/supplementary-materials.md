## 1. 项目概述

### 1.1 项目名称
**multi-note-skill** - 全天候智慧学伴

### 1.2 项目定位
基于大模型的智能笔记生成系统，专注于学生学习场景，支持多模态输入、智能场景识别、增量更新、知识图谱等功能。

### 1.3 核心价值
- **多模态输入**：视频/图片/网页/音频 → 自动整理成笔记
- **智能识别**：自动识别学科、复杂度，选择最佳结构
- **增量更新**：新内容可添加到已有笔记，构建知识库
- **知识图谱**：构建知识点关联，推荐学习路径

## 6. 使用示例

### 6.1 基本使用

```javascript
import { createSmartNoteGenerator } from './core/smart-note-generator.js'

const generator = createSmartNoteGenerator()

// 从文本生成笔记
const result = await generator.generate('Python基础教程')

// 从视频生成笔记
const videoResult = await generator.generate('https://www.bilibili.com/video/BVxxx')

// 从图片生成笔记
const imageResult = await generator.generate('D:/images/lecture.png')
```

### 6.2 增量更新

```javascript
// 更新已有笔记
const updateResult = await generator.updateNote(
  'D:/notes/python-notes.html',
  '今天学习了函数定义',
  { changes: '添加函数内容' }
)

// 查看版本历史
const history = generator.getNoteVersionHistory('D:/notes/python-notes.html')

// 回退版本
await generator.revertNote('D:/notes/python-notes.html', 'v1.0.0')
```

### 6.3 知识图谱

```javascript
// 提取知识点
generator.extractAndAddKnowledge(noteContent, { subject: '编程' })

// 生成学习路径
const path = generator.generateLearningPath({
  studentId: 'student-001',
  subject: '编程',
  targetKnowledge: '函数',
  currentKnowledge: ['变量']
})

// 检测薄弱点
const weaknesses = generator.detectWeaknesses({
  studentId: 'student-001',
  subject: '编程',
  learningRecords: { ... }
})
```

## 9. 项目亮点

### 9.1 技术亮点

1. **多模态智能融合**：支持视频、图片、网页、音频等多种输入
2. **智能场景识别**：基于关键词和正则模式匹配，支持20+学科
3. **Token优化**：精简SKILL.md，按需读取references，节省71.9%
4. **知识图谱构建**：自动提取知识点，建立关联，推荐学习路径

### 9.2 应用亮点

1. **专注学生学习场景**：不是通用笔记工具，是学习专属
2. **多模态自动整理**：不需要手动写内容，直接发资料
3. **智能场景识别**：自动识别学科和复杂度
4. **增量更新**：笔记可以持续完善，构建知识库
