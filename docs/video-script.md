## 录制要求

### 画面要求

| 要求 | 说明 |
|------|------|
| **分辨率** | 1920x1080 |
| **帧率** | 30fps |
| **画面清晰** | 文字清晰可读 |
| **操作流畅** | 无卡顿、无延迟 |

### 音频要求

| 要求 | 说明 |
|------|------|
| **配音清晰** | 发音标准，语速适中 |
| **背景音乐** | 轻柔背景音乐，音量适中 |
| **音量平衡** | 配音和背景音乐音量平衡 |

### 录制工具推荐

| 工具 | 优点 | 缺点 |
|------|------|------|
| OBS Studio | 免费，功能强大 | 学习成本高 |
| Camtasia | 专业，易用 | 需要付费 |
| Bandicam | 轻量，性能好 | 需要付费 |
| Windows Game Bar | 免费，系统自带 | 功能简单 |

### 录制步骤

1. **准备阶段**
   • 准备好演示环境
   • 准备好演示数据
   • 测试录制工具

2. **录制阶段**
   • 按照脚本录制
   • 注意画面清晰
   • 注意操作流畅

3. **后期处理**
   • 剪辑多余部分
   • 添加字幕
   • 添加背景音乐
   • 导出MP4格式
